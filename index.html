Application 00 — Featured Build

PM Agent

Agentic AI project-management system — MCP · FastAPI · 3 AI surfaces
Production · Deployed
An agentic AI assistant for delivery managers. It ingests Jira delivery data, scores risk deterministically, then layers AI judgment on top — and runs inside the tools PMs already use: Claude, ChatGPT, and Microsoft 365 Copilot. Production, deployed on AWS.
Click either to enlarge
▸ Technical detail
FastAPI (Python) MCP Server (24 tools) AWS App Runner Docker → ECR PostgreSQL + pgvector Terraform IaC Anthropic Claude Amazon Bedrock
  • 24 MCP tools across 7 functional groups — Portfolio Visibility, Risk Intelligence, Roadmap & Release, People & Reporting, Scoring Operations, Personalization, and Data Ingestion. Role-filtered for two audiences — Product (roadmap, scope, release) and Delivery (risk, flow, people, ops) — each user sees only the tools that fit their job via get_my_tools.
  • 10-layer pipeline: Jira ingest → normalization → PostgreSQL → deterministic risk engine (Tier 1, always on) → LLM judgment (Tier 2, on demand) → analysis → synthesis → Core Agent API → MCP/OpenAPI/Copilot adapters → AI surface.
  • Audited LLM adapter — every Tier-2 call passes a 4-step chain in code: kill switch → governance approval → PII sanitization → audit log. Graceful degradation to Tier-1 rules on any failure.
  • NIST AI RMF 1.0 + PMI-CPMAI governance alignment — explainability, human oversight, data minimization, and lifecycle controls designed in at the architecture level.
  • Three AI surfaces: Claude (MCP — stdio + Streamable HTTP), ChatGPT (custom GPT via OpenAPI action), Microsoft 365 Copilot (declarative agent via Teams).
  • Terraform IaC — ECR repo, App Runner service, EventBridge nightly batch rescore, all declaratively managed.

Verable

Verable (formerly CareerIQ) — personalized AI career-intelligence platform
Production · Deployed
A private AI career-intelligence app: résumé fit/gap scoring and tailoring, company research, application strategy, and interview prep. Built on AWS serverless with a live Claude integration and invite-only sign-in. Production.
Click to open the walkthrough
▸ Technical detail
AWS Lambda S3 CloudFront Cognito (OAuth2/PKCE) SSM Parameter Store KMS Anthropic API
  • OAuth2/PKCE authentication via Cognito; invite-only access enforced end to end.
  • KMS-encrypted secrets management — API key stored as an SSM SecureString, never hardcoded or client-side.
  • Live LLM integration — Lambda proxy calls the Anthropic API directly; model-string cutover handled after a mid-cycle model retirement.
  • Solo-diagnosed a full CORS/auth debugging arc across 9 build sessions — stale IAM policy, duplicate CORS headers, API Gateway stage-prefix mismatches — resolved by moving to a Lambda Function URL.
Scope note: 5 prompt-configured modules — not a multi-agent system. No inter-module handoff or autonomous planning.

Application 03

Paceline

Engagement-health & margin-intelligence engine for professional-services firms
Working Prototype
Margin intelligence for consultancies and agencies. It turns the timesheet and sprint data a firm already has into earned-value health signals, a prioritized morning brief, and dollar-denominated forecasts — so a delivery lead sees which engagements are losing margin, and why, before it's too late to fix.
Click to enlarge the full walkthrough
▸ Technical detail
CloudFront + S3 (SPA) Cognito PKCE API Gateway + Lambda S3 JSON persistence
  • EVM-style signal engine — computes CPI/SPI/EAC/PAC per engagement and fires deterministic signals: revenue at risk, margin erosion, schedule slip, team over-burn, retainer over-service.
  • Fully AWS-native static SPA with a same-origin /api/* surface backed by API Gateway + Lambda, single JSON-document-per-firm persistence in S3.
  • Four methodologies scored natively — phase-gate, hybrid EV, Scrum, and Kanban, each with its own risk vocabulary.
  • Grounded "Ask Pacer" assistant — scoped to answer only from computed evidence, not general-purpose chat; an evidence panel traces every fired signal to its driving metric, phase, and team member.
Scope note: working prototype on a synthetic demo dataset — deliberately distinguished from the production apps (Verable, Delivery Insights). Enterprise SignalCore engine is decoupled and gated on an IP opinion letter.
